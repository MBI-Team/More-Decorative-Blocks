# More Decorative Blocks
更多装饰性方块

## 模组简介
### Introduction

More Decorative Blocks 是一个为 Minecraft 添加更多装饰性方块的模组，由 More Blocks and Items Team (MBITeam) 开发。

More Decorative Blocks is a Minecraft mod that adds more decorative blocks to the game, developed by More Blocks and Items Team (MBITeam).

## 支持版本
### Supported Versions

- Minecraft Forge 1.21 (51.0.33)
- Minecraft NeoForge 1.21 (21.0.167)

## 功能特性
### Features

- **多样化的装饰方块**：添加了各种风格的装饰性方块，包括砖块、瓷砖、石块等
- **精细的模型设计**：每个方块都有精心设计的3D模型
- **真实的碰撞箱**：碰撞箱与视觉模型完美匹配
- **创意模式标签页**：方块被组织在方便的创意模式标签页中
- **支持多种朝向**：许多方块支持不同的放置朝向

- **Diverse decorative blocks**: Adds various styles of decorative blocks, including bricks, tiles, stones, etc.
- **Detailed model design**: Each block has a carefully designed 3D model
- **Realistic collision boxes**: Collision boxes perfectly match visual models
- **Creative mode tabs**: Blocks are organized in convenient creative mode tabs
- **Support for multiple orientations**: Many blocks support different placement orientations

## 安装说明
### Installation Instructions

1. 确保已安装 Minecraft Forge 或 NeoForge 1.21
2. 下载 More Decorative Blocks 模组文件
3. 将模组文件放入 Minecraft 的 mods 文件夹中
4. 启动游戏，在创意模式中找到并使用新方块

1. Make sure Minecraft Forge or NeoForge 1.21 is installed
2. Download the More Decorative Blocks mod file
3. Place the mod file into Minecraft's mods folder
4. Start the game and find the new blocks in creative mode

## 使用说明
### Usage

- 在创意模式下，新方块位于砖块标签页和其他相关标签页中
- 部分方块（如火之书、水之书、平板电脑）可以右键点击打开/关闭
- 所有方块都支持正常的破坏和放置机制

- In creative mode, new blocks are located in the bricks tab and other relevant tabs
- Some blocks (like Fire Book, Water Book, Tablet) can be opened/closed by right-clicking
- All blocks support normal breaking and placing mechanisms

## 方块列表
### Block List

- **砖块系列**：各种风格的砖块方块
- **瓷砖系列**：白色瓷砖、淡蓝色瓷砖等，包括完整、破损和残缺版本
- **书籍系列**：火之书、水之书
- **科技系列**：平板电脑
- **石头系列**：碎石、鹅卵石等

- **Brick series**: Various styles of brick blocks
- **Tile series**: White tiles, light blue tiles, etc., including full, cracked, and chipped versions
- **Book series**: Fire Book, Water Book
- **Technology series**: Tablet
- **Stone series**: Gravel, cobblestone, etc.
